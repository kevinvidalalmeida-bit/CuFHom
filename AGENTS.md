# Public repository boundary

This repository is exclusively for the public linear CuFHom software: source,
documentation, tests, examples, and reproducible benchmark drivers, protocols,
and redistributable inputs.

Do not add unpublished manuscripts, LaTeX/PDF files, manuscript figures,
measurement records, archives, or nonlinear research, including nonlinear
material models and tests. Keep reserved work in the separate private checkout.

Run `python tools/check_public_tree.py --all` before every public push. Check
the complete commit history, not just the current files. `export-ignore`
filters downloadable archives; it does not remove files from Git history.

The user cancelled Zenodo publication. Do not publish or enable Zenodo archives.
