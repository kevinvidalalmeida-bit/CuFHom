# Publicación de CuFHom

1. Revisar el diff, las pruebas y los archivos que se añadirán.
2. Conservar los avisos de atribución de terceros.
3. Excluir entornos, binarios y resultados locales mediante `.gitignore`.
4. Crear el repositorio privado y abrir los cambios en una rama revisable.

CuFHom no incluye una licencia propia hasta que su autor la elija. Los avisos
de terceros se mantienen bajo `third_party/`.
